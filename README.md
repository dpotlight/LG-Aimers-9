## Phase 2 솔루션
포수가 요구한 위치에 공이 갔는지(제구 성공)를 투구마다 확률로 예측하는 과제입니다.

| 구성 | 내용 |
|---|---|
| 피처 | 입력 48컬럼에서 파생 피처 78개. 통산 누적에서 올해 성적만 분리, 비율에서 등판 길이 복원 등 데이터에 없던 값을 되살린 축이 핵심 |
| 모델 | CatBoost, NN EmbedMLP(30시드), HistGB, LightGBM 가중 앙상블 |
| 보정 | 앙상블 이후 확률 보정 11단계 (Platt, 투수 × 상황 오프셋, 등판 내 폼 등) |
| 검증 | 시즌 경계 분할, 평균 보정 후 비교, 위약 대조로 채택 판정 |

야구 가설 14가지를 세워 7개를 채택했고, 마지막 +74.76점은 모델 재학습 없이 보정 계층에서 나왔습니다.

## Phase 3 본선
과제가 바뀌어 투구를 Shadow(존 가장자리), Heart(한가운데), Failure(실패) 세 등급 확률로 예측하고, 투수별 제구 순위까지 함께 평가했습니다.
